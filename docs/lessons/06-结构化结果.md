# 第 6 课 · 结构化结果

> 能力：outputSchema、structuredContent、isError　｜　场景：扫描时部分失败　｜　里程碑：M2

## 讲解

pi 1.1 的工具结果有两份：content 给模型看，structuredContent 给程序和 UI（必须符合 outputSchema）。业务失败返回 isError: true，而不是抛错——这样 details 与 structuredContent 都能保留下来。传感器受损时扫描只拿到半个扇区：模型看到错误，UI 仍能画出部分结果。注意：核心不会把 structuredContent 写进 transcript，只能从 tool_execution_end 事件获取。
