# 第 13 课 · 提示分段与动态工具

> 能力：system sections、state.tools 差异　｜　场景：机库损坏后修复　｜　里程碑：M4

## 讲解

首条 system 消息声明了 mission / rules / tools_guide / station_status / watch_phase 五个 section（稳定在前，易变在后，利于前缀缓存）。机库受损时：station_status 用一条只含 sections 的 system 消息打补丁；dispatch_drone 从 agent.state.tools 移除，pi 在下一次请求前自动写入工具差异。网关不支持中途声明工具（§2.3），所以完整工具表走 tools 参数。

## 课程脚本

faux 模式下按以下步骤运行（同时是回归测试）：

1. 机库受损：dispatch_drone 从工具表消失，提示词里的舱段状态随之更新
2. 机库修复：工具回来了

## 关掉它会怎样

去掉动态工具：机库受损时 dispatch_drone 仍在工具表里，模型调用后只会得到一个错误
