# 第 2 课 · 流式思考

> 能力：thinking_* 事件、thinkingLevel、thinkingBudgets　｜　场景：同一问题分别用 off / low / medium　｜　里程碑：M1

## 讲解

thinkingLevel 决定 pi 向模型请求多少推理（GLM 使用 thinking: { type }）。同一个问题依次用 off / low / medium 各跑一次，比较请求条里的「思考」斜纹分段、频道中可折叠的思考内容，以及 AssistantMessage.thinkingLevel 字段。注意：glm-5.3-flash 实测会忽略 disabled，UI 按 usage.reasoning 如实显示。

## 课程脚本

faux 模式下按以下步骤运行（同时是回归测试）：

1. 思考档位 off
2. 思考档位 low
3. 思考档位 medium

## 关掉它会怎样

把思考档位固定为 off，对比 Inspector 中请求条的「思考」分段是否消失
