# 第 18 课 · 分类器

> 能力：classify()、自定义 ProviderClassifier、模型类型　｜　场景：采样 k=1 与 k=5 的对比　｜　里程碑：M6

## 讲解

网关不返回 logprobs，pi-ai 内置的分类器用不了。这里在 GLM provider 上注册了一个模型类型为 classifier 的模型和自定义 ProviderClassifier：把问题编译成工具 schema，用 flash 并行采样 k 次，以经验分布作为概率。k=1 时概率只能是 0 或 1；k=5 时出现 0.2、0.6 这样的中间值。界面上的概率条明确标注「采样估计」。classify() 从不 reject：失败体现在 stopReason。

## 课程脚本

faux 模式下按以下步骤运行（同时是回归测试）：

1. 分诊：采样 k=1
2. 分诊：采样 k=5

## 关掉它会怎样

把采样数 k 调成 1：每个概率都只能是 0 或 1，看不出把握有多大
