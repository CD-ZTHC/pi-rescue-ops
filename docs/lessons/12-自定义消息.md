# 第 12 课 · 自定义消息

> 能力：CustomAgentMessages、convertToLlm　｜　场景：无线电、站务、UI 旁白　｜　里程碑：M4

## 讲解

AgentMessage = LLM 消息 + 你声明合并的自定义消息（CustomAgentMessages）。本项目有 situation、radio、world_event、operator、compaction、ui_note 六种。convertToLlm 在每次请求前把它们转成模型能懂的 user 文本：只有最新一条态势完整渲染，旧的折叠成一行；ui_note 直接过滤。打开「模型看到的上下文」抽屉，左边是 agent.state.messages，右边是转换之后的结果。

## 课程脚本

faux 模式下按以下步骤运行（同时是回归测试）：

1. 一批自定义消息：无线电、站务、UI 旁白、态势

## 关掉它会怎样

在 convertToLlm 里不过滤 ui_note：旁白会被当成用户消息发给模型
