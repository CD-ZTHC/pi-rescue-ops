# 第 19 课 · 录制回放

> 能力：faux provider、响应工厂　｜　场景：回放一次真实班次　｜　里程碑：M7

## 讲解

fauxProvider 不只是测试替身：录制时把每个船员的 AssistantMessage、主管操作、审批决定、分诊结论写进 JSONL；回放时世界用同一个 seed，响应工厂按 system prompt 认出是哪个船员，取他的下一条录制回复，并等世界走到录制时的 tick 才送出。回放产生的工具调用序列必须与录制一致，否则报告首个分歧点。本课回放一段真实 GLM 班次（没有就用离线演示录制），完全不需要 API key。

## 课程脚本

回放 `recordings/` 下的录制：`glm-shift-01.jsonl` → `offline-demo.jsonl`（用第一个存在的）。

## 关掉它会怎样

篡改录制里的一次工具调用：回放会在第一个不一致的地方报告分歧
