# 第 7 课 · 拦截与审批

> 能力：beforeToolCall 的 block / terminate　｜　场景：无人机闯入耀斑区　｜　里程碑：M3

## 讲解

beforeToolCall 在参数校验之后、执行之前运行，可以返回 { block: true, reason } 拦截。这里的策略链是 stepGate → staleGuard → budgetGuard → dangerApproval：无人机航线经过耀斑区时，dangerApproval 发出审批请求并 await 主管的决定（30 秒超时视为否决）。被拦截的调用以 isError 的工具结果回到模型，模型换了绕行航线再申请。拦截时还可以附带 terminate，让运行在本批工具之后结束。

## 课程脚本

faux 模式下按以下步骤运行（同时是回归测试）：

1. 无人机闯入耀斑区：先被否决，换航线后批准

## 关掉它会怎样

关掉「危险操作审批」：无人机直接闯进耀斑区，燃料翻倍、机体受损

讲义面板里有一键开关：策略 `dangerApproval`（危险操作审批，作用于 `beforeToolCall`）。改完点「↻ faux 运行」再跑一次对比。
