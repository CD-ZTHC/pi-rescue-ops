# 第 20 课 · 低层循环

> 能力：agentLoop，与 Agent 的屏障语义对比　｜　场景：班末评审　｜　里程碑：M6

## 讲解

agentLoop() 是不带状态的低层循环：给它消息、上下文和配置，它返回事件流。这个事件流是「观察性」的——消费者处理得再慢，循环也不等，工具可能在消费者看到 message_end 之前就执行了。Agent 则把 awaited 的 subscribe 监听器纳入运行：message_end 处形成屏障，beforeToolCall 看到的状态里已经包含发起调用的那条 assistant 消息。评审结果里会显示两者的对照。
