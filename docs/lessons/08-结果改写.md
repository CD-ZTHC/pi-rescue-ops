# 第 8 课 · 结果改写

> 能力：afterToolCall 改写 content / structuredContent　｜　场景：地面站数据打码　｜　里程碑：M3

## 讲解

afterToolCall 在工具执行之后、tool_execution_end 之前运行，可以改写 content / details / structuredContent / isError / terminate。地面站的船舶登记里有船长姓名、电话、证件号：redact 策略把它们打码，模型只看到打码后的版本，原文留在 details.unredacted 供界面切换查看。注意 1.1 的合并语义：只返回 content 会让 structuredContent 被丢弃，所以两者必须一起返回。

## 课程脚本

faux 模式下按以下步骤运行（同时是回归测试）：

1. 查询船舶登记：afterToolCall 把个人信息打码后再交给模型

## 关掉它会怎样

关掉「个人信息打码」：船长姓名、电话、证件号原样进入模型上下文

讲义面板里有一键开关：策略 `redact`（个人信息打码，作用于 `afterToolCall`）。改完点「↻ faux 运行」再跑一次对比。
