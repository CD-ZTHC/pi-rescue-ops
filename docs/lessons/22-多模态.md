# 第 22 课 · 多模态

> 能力：ImageContent、model.input、工具结果图片、纯文本模型的自动降级　｜　场景：指挥官看不见火点，委派工程师看监控　｜　里程碑：M5

## 讲解

图片是 ImageContent。model.input 决定 pi-ai 如何处理：glm-5.3 只收文本，图片被 transformMessages 替换为占位文本；glm-5.3-flash 能看图，工具结果里的图片被拆成紧随其后的一条 user 消息。指挥官看不见图，有两种办法：委派给能看图的专家（第二步），或在 prepareRequest 里检测到未分析的图片时临时换成 flash 发这一次请求（第三步，「换眼睛」）。图片也占上下文：每个船员只保留最近 2 张。

## 课程脚本

faux 模式下按以下步骤运行（同时是回归测试）：

1. 一、指挥官（纯文本模型）自己扫描：图片被降级为占位文本
2. 二、委派：领航员（flash）替指挥官看图
3. 三、换眼睛：prepareRequest 发现上下文里有未分析的图片，这一次请求临时换成 flash

## 关掉它会怎样

打开「有图时换眼睛」：指挥官遇到图片时临时换成 flash 看图，不必委派

讲义面板里有一键开关：策略 `visionSwitch`（有图时换眼睛，作用于 `prepareRequest`）。改完点「↻ faux 运行」再跑一次对比。
