# 第 1 课 · 事件流

> 能力：prompt、subscribe、事件顺序　｜　场景：指挥官回应一条态势　｜　里程碑：M1

## 讲解

一次 prompt 会产生怎样的事件序列？agent_start → turn_start → message_start/end（态势）→ 流式 assistant 消息 → 工具执行 → 下一个 turn → agent_end。看 Inspector：每个 turn 是一个色块，请求条里的竖线是 TTFT，下方的甘特条是工具执行。stand_by 返回 terminate，所以运行在工具批次之后直接结束，不再发起请求。
